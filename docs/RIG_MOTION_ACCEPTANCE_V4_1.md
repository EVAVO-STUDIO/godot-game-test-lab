# Rig motion acceptance v4.1

This surface imports an exact hash-bound asset into a temporary Godot project,
instantiates it, inventories meshes, skeletons and animations, and samples
transforms at four times per animation. It fails when a nominal animation has no
measurable motion.

The result is technical evidence for human review. It is not permission to alter
a game repository, admit the asset to runtime, deploy a build or publish it.
