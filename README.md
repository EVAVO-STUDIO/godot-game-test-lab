# Godot Game Test Lab

Reusable automated development, build, runtime, visual inspection and QA system
for EVAVO Studio Godot game repositories.

Designed for Godot 4.6.2 and later.

Core objectives:

- Open and run any supplied Godot project
- Detect the project's required Godot version
- Validate imports, scripts, scenes and resources
- Capture editor, build and runtime errors
- Run projects in debug and release modes
- Launch and interact with playable game builds
- Capture screenshots, video, logs and frame evidence
- Perform automated keyboard, mouse and controller input
- Step through splash, menu, gameplay and failure flows
- Compare screenshots against approved visual baselines
- Detect crashes, freezes, broken navigation and missing assets
- Produce machine-readable QA reports
- Integrate with ChatGPT, Claude, agents, CI and EVAVO Dev Studio
- Support local Windows execution, containers and isolated workers
- Preserve evidence for every test run
