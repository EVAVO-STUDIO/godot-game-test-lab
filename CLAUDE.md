# Claude Contract for Godot Game Test Lab

Read `AGENTS.md`, `docs/PROJECT_INTEGRITY_AND_RECOVERY.md`,
`docs/INTERACTIVE_AGENT_QA.md`, `docs/NATIVE_WINDOWS_AGENT_QA.md`, and
`evavo.reliability.json` before acting.

Work directly on `main`, preserve unrelated work, stop on drift, and publish only
through the governed Development Studio process or an equivalent exact-scope,
non-forced direct-main operation. Do not create branches, pull requests, or new
Godot QA repositories.

Use this Lab for cross-repository integrity, C#/.NET validation, exact editor
import, recovery diagnosis, bounded boot/export, isolated Linux evidence, and
native Windows target-owned journeys. Use Godot Web Runtime for compatible
browser playtesting. Never claim runtime, visual, input, GPU, or desktop proof
from source tests or static audit alone.

Native QA requires exact clean Lab and target SHAs, a tracked strict schema-2
profile, a disjoint external evidence root, an exact link-free archive copy,
bounded process/output/artifact budgets, the single desktop lease, and Explorer
in the same nonzero Windows session. Submodules fail closed until explicitly
materialized. Renderer, driver, GPU index, steps, assertions, and visual policy
belong in the tracked target profile.

The user-facing `godot-lab --scene` option must be converted to Godot's validated
positional scene argument. Unknown engine options may be ignored and are not
execution evidence.

Schema-2 journeys inject bounded Godot `InputEvent` objects. Synthetic keyboard,
mouse, and joypad events may prove declared event routing and state changes, but
not physical devices, Steam Input, rumble, latency, complete gameplay,
accessibility, game feel, or human visual approval.

Never edit, commit, push, deploy, sign, or publish a target game without a
separate Development Studio grant and the target repository's own exclusive
mainline lease. Every claim must identify the exact target SHA and the evidence
boundary that passed.

Deterministic bot QA uses `godot-lab-init-qa` and `godot-lab-bot-qa`. It performs bounded runtime UI graph exploration and InputMap fuzzing in fresh processes with isolated user data. Preserve exact trace evidence and deny destructive actions. Synthetic device events are not physical-controller certification or human visual approval.
