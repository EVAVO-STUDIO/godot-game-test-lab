# Pixel Font Admission

`godot-lab-pixel-font` independently validates a game-owned EVAVO bitmap-font family.

Without native Godot evidence the report is `source-passed-native-pending`.
Only exact Godot 4.6.2 render evidence with the required semantic roles, screenshot identities, zero import errors, and zero console errors can produce `status = passed`.

The source admission independently reopens the game runtime manifest, verifies its self-hash, exact atlas/BMFont/Godot-resource identities, PNG CRCs and dimensions, required semantic roles, smoothing policy, and the Godot nearest-filter/integer-scale/pixel-snap contract.

Native evidence uses schema `evavo.godot-pixel-font-native-evidence.v1` and must bind the exact game head, Godot 4.6.2, required rendered roles, and exact screenshots beneath the approved game root.

This admission never creates creative, historical, native-composition, provenance, candidate-promotion, repository-mutation, Git, publication, or force-push authority.
